Frontend - JS / TS / HTML / CSS

Closure? + debounceTop

Function + its lexical env remembers outer vars after return. Uses: private counter, debounce, memoize.

function outer(){let c=0;return ()=>++c}
const debounce=(fn,d)=>{let t;return(...a)=>{clearTimeout(t);t=setTimeout(()=>fn(...a),d)}}

Project: 300ms debounce on user search cut API calls ~70%.

Event loop?

Stack runs sync → all microtasks (Promise.then, await) drain → one macrotask (setTimeout, I/O) → render. So Promise beats setTimeout 0.

console.log(1);setTimeout(()=>console.log(2),0);Promise.resolve().then(()=>console.log(3)) // 1,3,2
Debounce vs throttle? Code?

Debounce = wait idle then run (search). Throttle = max once per limit (scroll).

const throttle=(fn,l)=>{let f=false;return(...a)=>{if(!f){fn(...a);f=true;setTimeout(()=>f=false,l)}}}
Promises: all vs allSettled vs race vs any?

all = fail-fast parallel fetch; allSettled = wait all (dashboard widgets); race = first settled (timeout); any = first fulfilled (CDN fallback).

await Promise.all([fetchA,fetchB])
await Promise.race([fetch(u),new Promise((_,rj)=>setTimeout(()=>rj(new Error('timeout')),5000))])
== vs ===? ?? vs ||? ?.?

Always ===. || falls on any falsy (0,''), ?? only null/undefined, ?. safe access.

user?.name ?? 'Guest'; const qty = 0 ?? 10 // 0 (|| would give 10 — payroll bug)
Deep copy?

structuredClone(obj) best — handles Date/Map/circular. JSON loses Dates/functions. Spread is shallow.

this + arrow?

Regular this = caller-dependent; arrow = lexical from definition. Use arrow for callbacks/map to keep component scope.

CORS? XSS vs CSRF?

CORS = browser blocks cross-origin; fix server cors({origin:[allowlist]}). XSS = injected script → escape, textContent, DOMPurify, CSP. CSRF = forged cookie request → SameSite + token. JWT refresh in HttpOnly SameSite cookie.

TS: interface vs type? any vs unknown?

interface = extendable object/merging (models); type = unions/tuples. any = opt-out (danger); unknown = must narrow (prefer for API JSON).

interface User{id:string;email:string} type Role='admin'|'user'
let v:unknown = await res.json(); if(typeof v==='object'&&v!==null){/* narrow */}
TS Generics + Utilities?

Reusable type-safe helpers + built-ins.

function first<T>(a:T[]):T|undefined{return a[0]}
type Public = Omit<User,'password'>; type Update = Partial<Pick<User,'name'>>
HTML: defer vs async? Semantic? a11y?

defer = parallel download, ordered exec after parse (your app). async = ASAP unordered (ads). Semantic header/nav/main/article for SEO+screen readers. a11y: label-for, alt, focus-visible, aria-label, contrast.

<script src="app.js" defer></script>
<label for="e">Email</label><input id="e">
CSS: Flex vs Grid? Center?

Flex = 1D row/col (nav, list). Grid = 2D rows+cols (dashboard).

.c{display:flex;align-items:center;justify-content:center}
/* or */ .c{display:grid;place-items:center}
Box model? Specificity? Position?

content+padding+border+margin; *{box-sizing:border-box}. Specificity: inline>id>class>element. Positions: relative (anchor), absolute (nearest positioned), fixed (viewport), sticky (scroll, needs top).

Reflow vs repaint?

Reflow = layout recalc (width) expensive; repaint = pixels (color) cheap; transform/opacity composite cheapest — animate with transform, not left/top.

var vs let vs const?

var = function-scoped, hoisted undefined; let/const = block-scoped, TDZ error before init. Use const default.

for(let i=0;i<3;i++) setTimeout(()=>console.log(i),0) // 0,1,2
fetch + AbortController?

Cancel stale search in cleanup; always check res.ok (fetch resolves 404).

const c=new AbortController(); const r=await fetch(u,{signal:c.signal}); if(!r.ok) throw new Error(r.status)

React + Redux

useEffect vs useLayoutEffect? Cleanup?Top

useEffect after paint (fetch, subs). useLayoutEffect before paint (measure DOM, avoid flicker). Return cleanup aborts fetch/timers. [] = mount only, [id] = re-run.

useEffect(()=>{const c=new AbortController();fetch(`/api/p/${id}`,{signal:c.signal}).then(r=>r.json()).then(setD);return ()=>c.abort()},[id])
useMemo vs useCallback vs memo?

useMemo = cached value (expensive filter); useCallback = cached fn (stable child prop); memo = cached component. Only for expensive/referential stability.

const f=useMemo(()=>list.filter(p=>p.name.includes(q)),[list,q])
Keys? Why not index?

Stable identity for diff. Index breaks on reorder/filter → wrong input state. Use id.

{items.map(p=><Card key={p.id} p={p}/>)}
Controlled vs uncontrolled?

Controlled = value+onChange, live validation (prefer). Uncontrolled = ref/defaultValue (file input).

Context perf pitfall?

All consumers re-render on any value change. Fix: split contexts (Auth/User), memo value.

const v=useMemo(()=>({user}),[user]); <Auth.Provider value={v}>
Fetch race fix?
useEffect(()=>{let ok=true;const c=new AbortController();fetch(url,{signal:c.signal}).then(r=>r.json()).then(v=>ok&&setD(v));return ()=>{ok=false;c.abort()}},[url])
Redux Toolkit flow?

createSlice → configureStore → Provider → useSelector/useDispatch. Immer lets you push mutably. Async via createAsyncThunk pending/fulfilled.

export const fetchP=createAsyncThunk('p/fetch',async()=>{const r=await fetch('/api/p');if(!r.ok)throw new Error('fail');return r.json()})
Normalize? RTK Query?

Normalize {ids,entities} via createEntityAdapter = O(1) update for 2k rows. RTK Query caches CRUD with tags/invalidate, replaces manual thunk+loading.

Redux vs Context vs Zustand?

Context = low-freq theme/auth; Redux = complex shared + devtools + middleware; Zustand = lightweight less boilerplate.

Optimistic update?

UI first, rollback on fail (likes). Pessimistic for money (wait 201).

setLiked(true); try{await api.like()}catch{setLiked(false)}
Testing (RTL)?
render(<Search/>); fireEvent.change(screen.getByPlaceholderText(/search/i),{target:{value:'phone'}}); expect(await screen.findByText(/phone/i)).toBeInTheDocument()

Backend - Node+Express / .NET

Express middleware + error handler?Top
function auth(req,res,next){const h=req.headers.authorization;if(!h?.startsWith('Bearer '))return res.status(401).json({message:'No token'});try{req.user=jwt.verify(h.slice(7),process.env.JWT_SECRET);next()}catch{return res.status(401).json({message:'Invalid token'})}}
app.use((err,req,res,next)=>res.status(err.status||500).json({message:err.message||'Server error'}))
JWT flow? Where store?

Login verifies bcrypt → access 15m + refresh 7d. Client sends Authorization: Bearer <access> → verify → req.user. Access in memory, refresh HttpOnly Secure SameSite cookie. Never localStorage (XSS). Logout clears cookie + deletes DB refresh. Reuse detection → logout-all.

Hash? Validation? REST?

bcrypt.hash(pwd,12) + compare. Validate at boundary with zod → 400. REST: GET/POST/PUT(full)/PATCH(partial)/DELETE; 200/201(+Location)/204/400/401/403/404/409/429.

Pagination? Cache? Rate limit?

Cursor ?cursor=&limit= for infinite (fast 1M rows); offset ?page= admin + cap limit 50. Redis GET key 60s + invalidate on write. express-rate-limit (login 5/min) + helmet + cors allowlist.

.NET pipeline? DI?

UseRouting → Authentication → Authorization → MapControllers. DI: Singleton (stateless), Scoped per-request (DbContext), Transient. [Authorize(Roles="Admin")], await _db.ToListAsync(), IOptions, Serilog.

401 vs 403? Idempotency?

401 = no/invalid token (login again); 403 = valid but no permission. POST payment retries safe via Idempotency-Key header stored 24h.

MongoDB vs Postgres

Embed vs reference? (Mongo)Top

Embed together-read <100 (user+address, order items snapshot). Reference many/shared (posts/userId). 16MB doc limit → bucket reviews per product.

Index? Aggregation?

db.users.createIndex({email:1},{unique:true}); compound {userId:1,createdAt:-1} for feeds.

db.orders.aggregate([{$match:{status:'paid'}},{$group:{_id:'$userId',total:{$sum:'$amount'}}},{$sort:{total:-1}}])

explain('executionStats'): COLLSCAN → add index → IXSCAN (login 800ms→40ms).

JOINs? N+1? (PG)

INNER = match only; LEFT = all left + nulls. N+1 = loop of 100 queries → fix with one JOIN/batch + FK index. Keyset WHERE id>$1 LIMIT 20 faster than OFFSET on large tables.

SELECT p.*,u.name FROM posts p JOIN users u ON u.id=p.user_id;
-- stock: UPDATE products SET stock=stock-1 WHERE id=$1 AND stock>0 RETURNING *;
ACID? Transaction?

Atomic/Consistent/Isolated/Durable. Money/stock: BEGIN → UPDATE... → COMMIT; race: SELECT...FOR UPDATE; Node: pool.connect + try BEGIN/COMMIT catch ROLLBACK finally release.

2nd highest salary?
SELECT MAX(salary) FROM emp WHERE salary < (SELECT MAX(salary) FROM emp);

Bonus - Next.js / NestJS / Cloud

SSR vs SSG vs ISR?

SSR per-request (personalized), SSG build-time (blog), ISR revalidate 60s (catalog: SEO + fresh), CSR client (dashboard). Catalog=ISR.

fetch(url,{next:{revalidate:60}})
Server vs Client components?

Server default: fetch DB, no hooks, SEO via metadata. Client "use client": state/events. Keep client low in tree for small bundle.

NestJS blocks? Guard vs Pipe?

Module→Controller→Service. Guard = allow? (auth), Pipe = validate/transform (ValidationPipe whitelist → 400), Interceptor = wrap logging/cache.

Azure vs GCP deploy?

Azure: App Service + Cosmos/Postgres + Static Web Apps. GCP: Cloud Run + Cloud SQL + Firebase. Secrets in Key Vault/Secret Manager (never repo), CI via GitHub Actions, health /healthz, Docker multi-stage + non-root.

function isValid(s){const st=[],m={')':'(','}':'{',']':'['};for(const c of s){if('([{'.includes(c))st.push(c);else if(st.pop()!==m[c])return false}return !st.length}

Git + HR + Mocks

Daily flow + rebase vs merge?

git pull --rebase → feat/x → push → PR squash → delete. Merge preserves history (main); rebase linearizes (feature). Never rebase shared main.

Conflict? Undo? Stash?

Status → edit <<<< → add → rebase --continue. revert = safe shared (new commit); reset --hard = danger local. stash push -m wip --include-untracked → pop.
